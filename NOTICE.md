# NOTICES / ATRIBUIÇÕES E CRÉDITOS

Este arquivo visa realizar a atribuição obrigatória de componentes de terceiros que compõem indiretamente a fundação gráfica e o roteamento de dados climáticos e métricas globais do `projeto_clima`.

## 1. APIs e Dados Demográficos
**Open-Meteo API**
- **Escopo**: Dados numéricos de Latitude, Longitude, Previsão Climática, Velocidade de Vento, Precipitações e Umidade Relativa.
- **Licenciamento Legal**: Gratuito para usos Estritamente Não-Comerciais sem necessidade de inserção de chaves e de tokens (*API Key Secrets*). O uso e atribuição pública dentro do projeto cumpre a forte documentação legal da API ("Attribution required is strict"). 
- **Site**: [https://open-meteo.com/](https://open-meteo.com/)

## 2. Bibliotecas de Interface (UI Fonts/SVGs)
**Weather Icons**
- **Artistas e Autor**: Erik Flowers (`erikflowers.github.io`)
- **Escopo**: Fornece os vetores das fontes de ícones base (Formato Fonte TTF/EOT em sua própria importação via CDN global) de todo o clima injetado do projeto pelo Javascript: vento, nuvens e instabilidades meteorológicas.
- **Licenciamento Legal**: Licenciado ao público sob a conformidade de respeito de Fontes da **SIL OFL 1.1** e os códigos/estilos nativos das classes sob conformidade do Github da MIT License.
